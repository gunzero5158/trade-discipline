# 持仓纪律工具 trade-discipline

按一套预设的交易纪律，每天收盘后自动算出每只持仓股明天的止损硬线价格和均线软线状态，告诉你明天该做什么。自用工具，不下单，不选股。

## 文档

- [交易纪律](docs/交易纪律.md)：规则本体。止损怎么放、仓位怎么算、浮盈分段怎么挪硬线、追涨和加仓的条件、账户级风控。
- [开发文档](docs/开发文档.md)：怎么把这套纪律做成工具。技术选型、规则的精确计算定义、数据模型、页面、里程碑、部署。
- [方案补充与讨论疑问](docs/方案补充与讨论疑问.md)：多轮复盘讨论的修正项、状态机漏洞修补与待比对疑问（与原文档对照参考）。
- [点位回测工具方案](docs/点位回测工具方案.md)：独立开发的点位回测工具设计方案（历史波段起点共性挖掘、支撑压力与破位概率统计）。
