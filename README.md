# 持仓纪律工具 trade-discipline

一套严格执行交易纪律的辅助决策系统。每天收盘后自动计算每只持仓股明天的止损硬线价格、均线软线状态、分段保护机制与操作建议，杜绝主观情绪交易。不下单、不选股，专注于持仓管理与回撤控制。

---

## 核心特性

- **严格状态机与四重漏洞修补**：
  1. **分段锁（Max Stage Lock）**：浮盈段位单向递增，回撤不降段，防止保护线上移后回撤触发降段导致止损线下移。
  2. **三段首达减仓标示（Stage 3 Trim Flag）**：首次触及三段浮盈推荐减仓 1/3，减仓后锁定状态不再重复提示。
  3. **复合 R 值绝对锚定**：以初次建仓的 1R 绝对金额作为唯一归一化基准，真实反映分段平仓的复合盈亏比。
  4. **五轨单调棘轮（5-Way Ratchet Hard Line）**：明日硬线严格取 `max(今日硬线, 段位底线, 加仓保本线, 人工硬线, 初始止损线)`，永不向后倒退。
- **动态均线软线保护**：
  - 支持 MA/EMA 灵活配置，自动计算 20 日振幅动态容差（防盘中毛刺穿透）。
  - 两日连续破线确认机制与加速期均线锁定保护。
- **开仓与加仓精准计算器**：
  - 单笔风险上限（账户净值 1%）、单股集中度上限（25%）、全账户敞口警戒线（5%）。
  - 自动检测追涨风险（距均线超 1.5 倍 ATR 弹窗警示）。
  - 加仓保本与总台账防亏损校验。
- **复盘统计与第八节自动诊断警报**：
  - 胜率、盈亏比、综合期望 R 值分析。
  - 自动检测并提示「盈利回吐超 50%」、「未到硬线提前主观砍仓」、「已破软线未确认前恐慌离场」等纪律违规点。
- **独立点位回测工具**：
  - 历史波段支撑位、突破点分析与破位概率测算，支持一键将验证点位送入计算器。
- **多端与隐私安全**：
  - 24 位高强度防碰撞通行凭证（Access Code），支持跨设备无缝登录。
  - 完整 JSON 数据导入导出与重置，完全掌控个人交易资产数据。

## 技术架构

- **前端框架**：Next.js (App Router) + React 19 + TypeScript + Tailwind CSS
- **图表可视化**：TradingView `lightweight-charts` v5 专业级 K 线图与均线/硬线标记
- **数据持久化**：LibSQL / Turso + Drizzle ORM（免配置自动迁移，支持本地 SQLite 与云端 Turso 无缝切换）
- **实时与历史行情引擎**：复用并优化东方财富、腾讯等多通道行情接入，具备熔断与自动故障降级机制
- **测试框架**：Vitest 自动化单元测试与 API 集成测试套件

## 快速开始

### 1. 安装依赖

```bash
npm install
```

### 2. 环境变量配置（可选）

系统默认采用本地 SQLite (`file:dev.db`)，零配置即可开箱即用。若需连接云端 Turso 数据库，可在根目录创建 `.env`：

```bash
cp .env.example .env
```

### 3. 本地启动

```bash
# 开发模式
npm run dev

# 生产构建与启动
npm run build
npm start
```

打开浏览器访问 `http://localhost:3000` 即可开始使用。

### 4. 运行测试

```bash
# 执行全量单元测试与集成测试
npm test

# 类型检查
npx tsc --noEmit
```

## 系统模块结构

```text
src/
├── app/                      # Next.js 页面与 API 端点
│   ├── api/                  # 持仓、行情、回测、复盘、认证、定时快照接口
│   ├── calculator/           # 开仓/加仓纪律计算器
│   ├── position/[id]/        # 个股持仓详情、K线图与个性化规则配置
│   ├── trades/               # 交易日志、月度复盘与纪律诊断
│   ├── backtest/             # 历史波段点位回测工具
│   ├── settings/             # 账户通行码、资产设定与数据备份/恢复
│   └── page.tsx              # 今日监控看板
├── components/               # 导航栏、K线图表组件、加仓/平仓交互弹窗
├── lib/
│   ├── auth/                 # 通行码生成、哈希比对与会话鉴权
│   ├── backtest/             # 点位回测分析引擎
│   ├── db/                   # Drizzle ORM Schema 与 LibSQL 客户端
│   ├── market/               # A股实时/历史行情、K线重构、指标计算
│   └── rules/                # 交易纪律核心引擎（状态机、硬线、软线、决策树）
└── docs/                     # 交易纪律与技术架构规划文档
```

## 自动化定时任务 (Cron)

系统提供 `/api/cron/snapshot` 端点用于每日收盘后（15:05）自动对所有活跃持仓进行当日快照与次日风控线计算。

通过请求头或 Query 携带密钥调用：
```bash
curl -X POST "http://localhost:3000/api/cron/snapshot" -H "Authorization: Bearer dev-secret-key-change-in-production"
```
